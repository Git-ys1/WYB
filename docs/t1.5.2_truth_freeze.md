# T-1.5.2-R1 Truth Freeze

本轮唯一口径（用于代码审查与 FREQ 修复）：

- FREQ 主测量入口：`PA0 (TIM2_CH1)`。
- MODE 物理映射：`CH0=VOLTAGE, CH1=RES+CONT, CH2=DIODE, CH3=FREQ`。
- 蜂鸣器运行链：`PB1`，active-low（`Low=ON, High=OFF`）。
- 二极管激励：`PB0`（`ON=推挽高`, `OFF=Analog/Hi-Z`）。
- UI 正式交互：`RIGHT/LEFT`；`OK/BACK` 仅保留 dev-only 扫描。

本轮明确不做：

- 不改 `RES/DIODE/CONT` 的算法、阈值、显示语义。
- 不改 OLED/bootdiag 主链。
- 不做链路删除，仅做 retain/delete-later 审计。

# T-1.5.5 Truth Freeze（提交态唯一口径）

## 1. 主架构
- 运行框架：`HAL + superloop`。
- 显示链路：`app -> presenter -> app_display_service -> oled_smoke`（唯一写者）。
- 不允许并存第二套显示路径。

## 2. 引脚与硬件契约
- `PA0`：`TIM2_CH1`，FREQ 唯一输入。
- `PA1`：模拟公共采样链节点（OPAMP1/ADC）。
- `PB0`：DIODE 激励（ON=推挽高，OFF=Analog/Hi-Z）。
- `PB1`：蜂鸣器控制（active-low）。
- `PB4/PB5/PB6`：MODE CD4051 A/B/C。
- `PD5/PD6/PD7`：RES CD4051 A/B/C。
- `PB13/PB14`：VOLT CD4051 A/B。

## 3. 模式映射
- `MODE CH0 = VOLTAGE`
- `MODE CH1 = RES / CONT`
- `MODE CH2 = DIODE`
- `MODE CH3 = FREQ`

## 4. 输入与交互
- 正式功能键：`RIGHT`（短按切档，长按切功能）。
- 调试后门：`LEFT`（开/关 Debug），受编译开关控制。

## 5. 蜂鸣器与安全
- 正式蜂鸣器链仅 `PB1`，禁止并存 PB8/TIM16 运行链。
- 仅 CONT 模式允许持续鸣叫；离开 CONT 立即静音。

## 6. FREQ 唯一路线
- `PA0(TIM2_CH1) -> TIM2 capture -> BSP ticks snapshot -> drv_freq_ic -> app`。
- 禁止回退到 ADC/COMP/DMA 另一路线。

## 7. 开机显示
- OLED 初始化成功后显示 2 秒位图开机画面：
  - `数字万用表`
  - `李浩天`
  - `23291043`
- 之后进入主 UI。

## 8. 已知问题
- `VDC 20V` 问题保留为已知项，后续单任务修复。

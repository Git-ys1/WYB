# T-1.5.5 Cleanup Report

## 目标
- 清理与提交态冲突的历史链路，确保“一个功能一条正式链路”。
- 本报告只覆盖本轮实际删除/冻结的内容。

## 删除项与替代关系

| 删除项 | 删除原因 | 替代链路 | 影响评估 |
|---|---|---|---|
| `App/app_heartbeat.c` `App/app_heartbeat.h` | 历史 TIM6 诊断链，不再参与正式诊断 | `app_bootdiag` + `PB12` 心跳/故障灯 | 无功能回归 |
| `App/app_menu_tree.c` `App/app_menu_tree.h` | 历史菜单壳残留，当前运行路径不使用 | 当前比赛态 `RUN_MAIN/RUN_DEBUG` 视图 | 无功能回归 |
| `main.c` 中 `I2C3/TIM16` 初始化与句柄 | 历史链路，与提交态冲突 | 正式仅保留 `I2C2 + TIM2` | 无功能回归 |
| `stm32g4xx_hal_msp.c` 中 `I2C3/TIM16` MSP 代码 | 同上 | `I2C2/TIM2` MSP | 无功能回归 |
| `stm32g4xx_it.c` 中 `TIM6/EXTI15_10` 相关处理 | 历史中断链，已无正式依赖 | `TIM2 IRQ` + `bootdiag` | 无功能回归 |
| `BSP` 层 `bsp_pwm_*` 与 `BSP_I2C_BUS_ADS` | 历史兼容接口，不再用于正式链 | `drv_beep` 直控 PB1 + `BSP_I2C_BUS_OLED` | 无功能回归 |
| `drv_beep.c` 历史 fallback 分支 | 避免同功能多后端并存 | 固定 PB1 active-low 唯一后端 | 行为更可控 |
| `drv_mux4051.h` 中 `MUX_MODE_AC` 兼容别名 | 语义落后，易误导 | 统一 `MUX_MODE_FREQ` | 文义统一，无行为变化 |

## 保留但冻结项
- `measure_res / measure_diode / measure_cont` 算法未改。
- `FREQ` 主链未改路线，仅保留模块内热修扩展位（`icpsc/no_sig_timeout_ms/accum_cycles`）。
- `VDC 20V` 作为已知问题保留。

## 3. 与 CubeMX 对接步骤（可直接照做）

## 3.1 在 CubeMX 新建工程
1. 选择芯片：`STM32G474VET6`。
2. 配置引脚/外设：
- I2C3：`PC8(SCL)`, `PC9(SDA)`（ADS1110）
- I2C2：`PC4(SCL)`, `PA8(SDA)`（OLED）
- GPIO Output：`PD5/PD6/PD7`（RES MUX）
- GPIO Output：`PB4/PB5/PB6`（MODE MUX）
- GPIO Output：`PB13/PB14`（VOLT MUX）
- TIM 输入捕获：`PA0`（建议 TIM2_CH1）
- KEY：`PC13`（EXTI）
- BEEP：`PB8`（TIM16_CH1 PWM）

3. 时钟和中断：
- 打开 KEY EXTI 中断。
- 打开输入捕获定时器中断。
- 保证用于输入捕获的定时器时钟足够高（保证占空比分辨率）。

4. 生成工程：建议生成到新目录（例如 `cube_fw/`）。

## 3.2 拷贝 T-0.1.8 代码
把以下内容复制进 Cube 工程：
- `App/`
- `Drivers/`
- `Measurements/`
- `Calib/`
- `BSP/`
- `main.c`

并确保编译器包含路径包含这些目录。

## 3.3 实现 BSP 映射（关键）
文件：`BSP/bsp_port_hal_template.c`

你需要把模板中的 TODO 映射到 CubeMX 生成句柄：
- I2C2/I2C3 -> `HAL_I2C_*`
- GPIO -> `HAL_GPIO_WritePin/ReadPin`
- PWM(PB8/TIM16_CH1) -> `HAL_TIM_PWM_Start/Stop` + ARR/CCR 设置
- 输入捕获(PA0) -> 在 `HAL_TIM_IC_CaptureCallback` 中缓存周期/高电平时间，并在 `bsp_freq_get_capture()` 返回
- Tick/Delay -> `HAL_GetTick/HAL_Delay`

## 3.4 主循环接入
在主函数中保持：
```c
while (1) {
    app_poll_button();
    app_measure_tick();
    app_ui_tick();
    app_beep_tick();
}
```

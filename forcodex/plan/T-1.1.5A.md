# T-1.5.1A 执行计划（基于已通过 OLED Smoke 基线：固定文本 + ADC1/PC0 Bring-up）

## 摘要
本轮只做三件事：  
1. 修掉当前唯一 warning（`init_b` 未使用）。  
2. 把“Codex 使用 STM32CubeIDE 编译”的方法写入 `README.md`（含可复用命令）。  
3. 在 OLED Smoke 路径上实现“固定文本页 -> 固定 ADC 调试页（RAW/MV/VDDA/STAT）”。  

不删除旧业务逻辑，不恢复旧复杂 OLED 路径（Soft-I2C/recover/dirty/menu 并发刷新都不恢复）。

## 公共接口/类型变更
在 `bsp_oled_smoke` 新增最小文本渲染接口（保持现有接口不删）：
1. `void oled_smoke_fb_clear(uint8_t fill);`
2. `void oled_smoke_draw_text_line(uint8_t line, const char *text);`  
3. `bool oled_smoke_flush_full(void);`

说明：`line` 采用 page 行（0~7），固定 `y = line * 8`，只走整屏 flush，不引入 dirty flush。

## 实施步骤
1. 修 warning。  
把 `bsp_oled_smoke.c` 里 `init_a/init_b` 改成编译期单分支声明（`#if OLED_INIT_PROFILE_A` 只声明 A，`#else` 只声明 B），消除 `unused variable 'init_b'`。

2. 固化 README 编译方法。  
在 README 增加 “STM32CubeIDE 编译（GUI + headless）”章节。  
写明 GUI 一键 Build 路径。  
写明 headless 命令（Codex用）并注明“IDE占用 workspace 会锁定，需单独 headless workspace”：
`F:\CodeForge\STM32CubeIDE_2.1.0\STM32CubeIDE\stm32cubeidec.exe --launcher.suppressErrors -nosplash -application org.eclipse.cdt.managedbuilder.core.headlessbuild -data F:\CodeForge\STM32CubeIDE_2.1.0\WorkSpace3_headless -import F:\CodeForge\STM32CubeIDE_2.1.0\WorkSpace3\WYB -cleanBuild WYB/Debug`

3. 保持 Smoke 三路分流不变。  
`APP_SMOKE_OLED_TEST=1` 路径继续独立运行，不进入 `bsp_init/app_init/app_*tick`。  
LED smoke 和原业务路径保留原样，不删除。

4. 实现固定文本 Smoke（Step1）。  
在 OLED smoke 路径上电后先显示固定 4 行：  
`OLED TXT OK`  
`ADC INIT...`  
`RAW: ----`  
`MV : ----`  
刷新周期固定 500ms，整屏 flush，连续运行稳定。

5. 接入片内 ADC Bring-up（Step2）。  
在 OLED smoke 路径调用现有 `adc1_init()`。  
读取接口用现有 `adc1_read_raw_u16/adc1_read_mv/adc1_read_vdda_mv`。  
保持长采样、VREFINT失败回退3300mV（沿用现有实现，不改算法）。

6. 升级为固定 ADC 调试页（Step3）。  
固定显示 5 行（无菜单、无按钮依赖）：  
`OLED TXT OK`  
`RAW: xxxxx`  
`MV : x.xxx`  
`VDDA: xxxx`  
`STAT: OK/ERRn`  
即使 ADC 失败也继续刷新 OLED，仅变更 `STAT` 和占位值，不进入错误死循环。

7. 文档同步。  
`validation_checklist.md` 增加 `T-1.5.1A` 条目。  
`oled_driver_report.md` 增补“本轮沿用已通过 OLED 底层参数，新增固定文本+ADC页验证”。

8. 构建验证。  
执行 headless `cleanBuild WYB/Debug`。  
通过标准：0 error，且不再出现 `init_b` unused warning。

## 测试用例与场景
1. `T151A-BUILD-01`：headless clean build 通过，`init_b` warning 消失。  
2. `T151A-OLED-TXT-01`：固定文本页连续 5 分钟无黑屏/花屏。  
3. `T151A-ADC-INIT-02`：`adc1_init()` 成功，STAT 显示 `OK`。  
4. `T151A-ADC-GND-03`：PC0 接 GND，RAW≈0，MV≈0。  
5. `T151A-ADC-3V3-04`：PC0 接 3.3V，RAW 接近满量程，MV 接近 3300。  
6. `T151A-ADC-RED-05`：PC0 接 RED 节点，RAW/MV 随节点变化。  
7. `T151A-ADC-ERR-06`：模拟 ADC 异常时 OLED 继续刷新，`STAT: ERRn` 可见。

## 显式假设与默认
1. OLED 继续使用当前已验证通过参数：SSD1315 路径、HW I2C2、100k、page mode、0x00/0x40、16B chunk。  
2. `APP_SMOKE_OLED_TEST` 本轮默认保持 `1`，用于先完成 ADC bring-up 验证。  
3. 旧电阻测量和菜单逻辑保留但不参与本轮执行。  
4. 输入电压对 PC0 始终限制在 `0~3.3V`。

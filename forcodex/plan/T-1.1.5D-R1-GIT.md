## 执行步骤（决策完备）
### 1. 仓库规范化（不重建仓库）
在 `WYB` 根目录执行：
1. `git branch -M main`（统一主分支为 `main`）
2. `git config user.name "Git-ys1"`
3. `git config user.email "3091964993@qq.com"`

说明：已存在 `.git`，本轮不再 `git init` 重建。

### 2. 建立 `.gitignore`（强制）
在根目录新增 `.gitignore`，至少包含：
- `Debug/`

- `*.elf`
- `*.hex`

- `*.d`

- `*.log`

- `Thumbs.db`

### 3. 清理当前索引污染（关键）
由于当前大量编译产物已被 staged，按固定顺序执行：
1. `git reset`（仅撤销暂存，不丢工作区）
2. `git add .gitignore`
3. `git add .`
4. `git status` 检查：`Debug/Release` 和编译产物不得再进入 staged

### 4. 首次稳定基线提交
提交信息固定：
- `baseline: stable oled+adc smoke after rollback`

执行：
1. `git commit -m "baseline: stable oled+adc smoke after rollback"`
2. 记录提交哈希到 `docs/git_workflow.md`（作为基线锚点）

### 5. 绑定 GitHub 远程并首次推送
远程固定：
- `origin = https://github.com/Git-ys1/WYB.git`

执行：
1. `git remote add origin https://github.com/Git-ys1/WYB.git`（若已存在则 `set-url`）
2. `git push -u origin main`

可见性策略：
- 默认 private（你已指定“优先 private”）

### 6. 新增 `docs/git_workflow.md`（强制流程文档）
文档固定包含：
1. 仓库信息（repo/branch/user/email）
2. 每轮开始前命令（必须）：
   - `git status`
   - `git add .`
   - `git commit -m "checkpoint: before <TASK_ID>"`
   - `git push`
3. 每轮结束后命令（必须）：
   - `git status`
   - `git add .`
   - `git commit -m "<TASK_ID>: <summary>"`
   - `git push`
4. 回退策略（固定三种）：
   - 未提交：`git restore .` / `git restore <file>`
   - 已提交安全撤销：`git revert HEAD`
   - 本地硬回退：`git reset --hard HEAD~1`
5. 提交命名模板（baseline/checkpoint/task）
6. 禁止事项：未 checkpoint 禁止开改；不允许长期本地未 push

### 7. 更新 README（加入“以后每轮必须执行”）
在 README 增加“Git 工作纪律”章节，内容与 `docs/git_workflow.md` 对齐，明确：
- 每轮开始前必须 checkpoint+push
- 每轮结束后必须 task commit+push
- 回退优先级：`restore -> revert -> reset --hard`

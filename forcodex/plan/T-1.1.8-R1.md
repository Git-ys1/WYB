# T-1.1.8-R1 执行计划（比赛态单键逻辑 + RES前端健康门控 + OPAMP迁移准备）

## 摘要
基于当前 `WYB` 分支现状（`exp/menu-tree-r1`，显示链路稳定，`RES_RUN` 已有但结果不可靠），本轮不再推进多级菜单功能，改为“比赛态交互 + 诊断后门”：

1. **UI 交互收敛**：正式逻辑只用 `RIGHT`（短按切档、长按切功能）+ `LEFT`（进/退 Debug）。  
2. **电阻结果降级保护**：先过 AFE 端点健康判定，未通过一律不显示 R（`R: ----`, `STAT: AFE BAD`）。  
3. **为下轮 OPAMP 迁移做软件收口**：把 `measure_res` 拆成“采样/判定/计算/显示格式化”四段，后续只替换采样段。

## 三、交互与页面模型（正式路径）

## 1) 按键口径（2键比赛态 + dev后门）
- `RIGHT short`：当前功能内切档（+1循环）
- `RIGHT long`：切功能（`RES -> VDC -> FREQ -> CONT -> DIODE -> RES`）
- `LEFT short`：进入/退出 Debug 页
- `LEFT long`：忽略
- `OK/BACK`：**不参与正式运行逻辑**（可保留扫描，但正式状态机不消费）

> 说明：当前 `bsp_keys` 已是 4键；本轮不再回到 6键，也不让 `OK/BACK`参与正式 UI 路径。

## 2) 页面收敛（不走多级菜单）
引入运行视图枚举（放 `app.c` 内部）：
- `VIEW_RUN_MAIN`：正式比赛页
- `VIEW_RUN_DEBUG`：调试后门页

上电默认 `VIEW_RUN_MAIN`。

## 3) 正式页固定布局（4行）
- 行1：`FUNC: RES/VDC/FREQ/CONT/DIODE`
- 行2：`RANGE: AUTO/200 EXP/2K/20K/200K`（当前功能对应档位）
- 行3：主数值（RES 下为 R；其他功能显示 `READY`）
- 行4：状态/辅助量（RES 下显示 `STAT` + `MV/RAW`简要）

## 四、measure_res 重构（四段式，决策冻结）

新增/重构为四段接口（`Measurements/measure_res.*`）：

## 1) 采样
```c
typedef struct {
    bool valid;
    uint16_t raw_u16;
    uint32_t mv;
    uint32_t vdda_mv;
    app_err_t err;
} res_sample_t;

app_err_t res_acquire_sample(uint8_t range_sel, res_sample_t *s);
```
- 调用 `adc1_read_filtered` + `adc1_read_vdda_mv`（失败回退 3300mV）
- 配置 MUX（保持现有链路）

## 2) AFE健康判定
新模块 `res_afe_diag.*`：
```c
typedef struct {
    bool short_seen;
    bool open_seen;
    bool afe_ok;
} res_afe_health_t;

void res_afe_diag_reset(uint8_t range_sel);
void res_afe_diag_update(uint8_t range_sel, const res_sample_t *s);
res_afe_health_t res_afe_diag_get(uint8_t range_sel);
bool res_check_afe_health(uint8_t range_sel, const res_sample_t *s);
```

判定逻辑（每档）：
- `SHORT` 观测条件：`mv <= SHORT_TH[range]`
- `OPEN` 观测条件：`mv >= vdda_mv - OPEN_MARGIN[range]`
- `afe_ok = short_seen && open_seen`

> 本轮策略：**只有 `afe_ok=true` 才允许计算并显示 R**。  
> 否则强制：`R: ----`, `STAT: AFE BAD`。

## 3) 估算
```c
app_err_t res_estimate_rx(uint8_t range_sel, const res_sample_t *s, float *r_ohm);
```
- `Rref` 固定：`200=100Ω, 2K=1kΩ, 20K=10kΩ, 200K=100kΩ`
- 公式：`Rx = Rref * Vred / (Vdda - Vred)`（`Vred=mv`, `Vdda=vdda_mv`）
- `AUTO` 返回 `ERR_NOT_IMPL`
- 200档参与计算但标记 `EXP`

## 4) 显示格式化
新模块 `res_display_fmt.*`：
```c
typedef struct {
    char line_value[22];   // e.g. "R: 1.234k"
    char line_stat[22];    // e.g. "STAT: OK", "STAT: AFE BAD", "STAT: OL"
} res_display_text_t;

void res_format_display(uint8_t range_sel,
                        const res_sample_t *s,
                        bool afe_ok,
                        bool calc_ok,
                        float r_ohm,
                        res_display_text_t *out);
```
3½位显示规则：
- 200档：`199.9Ω`
- 2K档：`1.999kΩ`
- 20K档：`19.99kΩ`
- 200K档：`199.9kΩ`
- 超量程：`OL`

## 五、App层接线（不破坏显示单写者）

## 1) `app_poll_button()`
- 仅处理 `RIGHT short/long` 与 `LEFT short`
- 不再让 `OK/BACK`改变正式页面状态

## 2) `app_measure_tick()`
- 周期保持 `MEAS_PERIOD_MS=40ms`
- 仅当 `VIEW_RUN_MAIN && mode==MODE_RES` 执行 RES链路：
  - `res_acquire_sample`
  - `res_afe_diag_update`
  - `res_check_afe_health`
  - `res_estimate_rx`（仅 afe_ok 时）
- 非 RES 功能不启动真实测量（保持 READY）

## 3) `app_ui_tick()`
- `UI_REFRESH_MS=200ms` 保持
- 仍通过 `app_ui_presenter_flush()` 单点输出
- `VIEW_RUN_DEBUG` 展示诊断（见下）

## 4) Debug后门页内容
固定展示：
- 当前功能/量程
- `RAW / MV / VDDA`
- `SHORT_SEEN / OPEN_SEEN / AFE_OK`
- 当前 `STAT`

用于你做端点记录（2K/20K/200K优先）。

## 八、验收测试场景（实测顺序）

1. 上电稳定性：5分钟无黑屏/花屏  
2. 键行为：
- RIGHT短按：档位循环
- RIGHT长按：功能循环
- LEFT短按：Debug开/关
3. RES端点健康（每档至少2K/20K/200K）：
- 短路红笔到GND，观察 `short_seen=1`
- 开路红笔悬空，观察 `open_seen=1`
- 两者满足后 `afe_ok=1`
4. R显示门控：
- `afe_ok=0` 时必须 `R: ---- / STAT: AFE BAD`
- `afe_ok=1` 后才显示 R
5. 200档行为：
- 标题/档位明确 `EXP`
6. 断OLED回归检查：
- PB12故障诊断行为不被破坏

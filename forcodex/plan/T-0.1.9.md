## 2. CubeMX 外设配置补齐（B 前置）
## 2.1 必配外设与引脚（冻结不改）
- I2C2: PC4/PA8（OLED）  
- I2C3: PC8/PC9（ADS1110）  
- TIM2_CH1 输入捕获: PA0（频率/占空比）  
- TIM16_CH1 PWM: PB8（BEEP）  
- GPIO 输出：PD5/PD6/PD7、PB4/PB5/PB6、PB13/PB14  
- EXTI：PC13（KEY）

## 2.2 具体配置

2. 保持 TIM2 为 `CH1 直连上升沿 + CH2 间接下降沿 + Reset mode(TI1FP1)`。  
3. 启用 TIM16 PWM 输出到 PB8（生成 `htim16` 与 `MX_TIM16_Init`）。  
4. 保留 EXTI15_10 与 TIM2 IRQ 使能。  
5. 重新生成后确认 `stm32g4xx_hal_conf.h` 里 `HAL_I2C_MODULE_ENABLED`、`HAL_TIM_MODULE_ENABLED` 生效。

## 4. BSP HAL 对接（B1）
对 [BSP/bsp_port_hal_template.c](F:/Project/stm32G474VETx/study/wanyongbiao/wanyongbiao/BSP/bsp_port_hal_template.c) 完整落地，去除 TODO：

1. I2C 映射  
- `BSP_I2C_BUS_OLED -> hi2c2`  
- `BSP_I2C_BUS_ADS  -> hi2c3`  
- `HAL_I2C_Master_Transmit/Receive/IsDeviceReady`，地址用 `addr7 << 1`。

2. GPIO 映射  
- `BSP_PIN_*` 对应 `main.h` 中宏：`RES_MODE_* / CHANNLE_SELEC_* / VOLTAGE_MODE_* / KEY / BEEP`。  
- 写：`HAL_GPIO_WritePin`；读：`HAL_GPIO_ReadPin`。

3. Tick/Delay  
- `bsp_millis -> HAL_GetTick`  
- `bsp_delay_ms -> HAL_Delay`

4. PWM  
- 优先 `TIM16_CH1`：按 `freq_hz` 配 ARR/CCR，`HAL_TIM_PWM_Start/Stop`。  
- 若 TIM16 不可用，GPIO 兜底：`bsp_pwm_start` 置高、`bsp_pwm_stop` 置低（接口不变）。

5. 输入捕获缓存  
- 在 BSP 内维护 `volatile` 缓存：`period_ticks/high_ticks/valid/timestamp`。  
- `bsp_freq_get_capture()` 把 tick 换算为 `period_us/high_us` 返回。

## 5. 中断回调对接（B2）
1. 在用户代码区实现 `HAL_TIM_IC_CaptureCallback`：  
- TIM2 CH1 更新周期 tick。  
- TIM2 CH2 更新高电平 tick。  
- 校验 `high <= period`，生成 `valid`。  

2. 实现 `HAL_GPIO_EXTI_Callback(GPIO_Pin)`：  
- 识别 `KEY_Pin`，记录边沿时间（供按键去抖参考，驱动仍以 `button_poll` 判短长按）。  

3. 在 `main` 初始化阶段启动：
- `HAL_TIM_IC_Start_IT(&htim2, TIM_CHANNEL_1)`  
- `HAL_TIM_IC_Start_IT(&htim2, TIM_CHANNEL_2)`

## 6. 驱动与算法联调顺序（C → D）
1. C1 OLED：I2C2 探测 0x3C/0x3D，刷自检页。  
2. C2 ADS1110：I2C3 连续读 raw/mV，GND/3V3 验证方向。  
3. C3 MUX：轮询 A/B/C 与 A/B，OLED 显示当前索引。  
4. C4 输入捕获：1kHz/30% 显示频率和 duty。  
5. D1/D2：按键短按切档、长按切模式，完成四项联测。  
6. D3：断开 OLED/ADS/PA0 无信号，验证 ERR 提示与恢复。

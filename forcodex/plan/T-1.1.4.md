# T-1.1.4 实施计划：移除 ADS1110，切换到 STM32G474 片内 ADC（PC0/ADC12_IN6）

## 摘要
目标是把当前工程的采样链路从 `ADS1110(I2C3)` 完整迁移到 `ADC1(PC0)`，并保持现有电阻手动档/菜单/UI可用。  
本计划按“先打通可测，再补精度”执行：  
1. 先用片内 ADC + 固定 `Vref=3300mV` 跑通。  
2. 同步接入 `VREFINT` 估算 `VDDA`，提升换算精度。  
3. 完整移除 ADS1110 驱动引用与 I2C3 扫描逻辑（I2C3 外设初始化先保留，后续可再从 `.ioc` 清理）。

---

## 已确认现状（来自仓库）
1. 当前工程仍依赖 `drv_ads1110.*`（`App/app.c`、`Measurements/measurements.*`）。  
2. 片内 ADC 尚未启用：`HAL_ADC_MODULE_ENABLED` 在 `stm32g4xx_hal_conf.h` 中注释状态。  
3. 工程 `Drivers/STM32G4xx_HAL_Driver` 当前缺少 ADC HAL 文件（`stm32g4xx_hal_adc*.h/.c`、`ll_adc`）。  
4. `.ioc` 中 `PC0` 未占用，可用于 `ADC12_IN6`。

## 对外接口/类型变更（必须执行）
1. 移除测量层 ADS 依赖：
- `measurements_init(const calib_profile_t *calib, ads1110_t *ads)`  
改为  
- `measurements_init(const calib_profile_t *calib)`  

2. 新增片内 ADC 驱动 API（`drv_adc_internal.h`）：
- `app_err_t adc1_init(void);`
- `app_err_t adc1_read_raw_u16(uint16_t *raw);`
- `app_err_t adc1_read_mv(uint32_t *mv);`
- `app_err_t adc1_read_filtered(uint16_t *raw, uint32_t *mv);`
- `app_err_t adc1_read_vdda_mv(uint32_t *vdda_mv);`
- `app_err_t adc1_read_status(void);`（返回上次采样状态，供 UI 显示 `OK/TIMEOUT/OVR`）

3. UI 模块状态位调整：
- `MOD_ADS` 替换为 `MOD_ADC1`
- 移除 `MOD_I2C3` 的自检显示位（不再扫描 ADS 地址）

4. 错误语义：
- `ERR_ADC_TIMEOUT` 保留，用于片内 ADC `PollForConversion` 超时  
- 片内 ADC overrun 统一映射 `ERR_HW_FAIL`（UI 显示 `OVR`）

## 设计决策（冻结）
1. **不改 `.ioc` 先完成迁移**：ADC1 由新驱动手工初始化（GPIOC/ADC12 时钟、PC0 Analog、ADC参数、校准）。  
2. 采样配置：
- 单通道、单次转换、软件触发  
- 通道 `ADC_CHANNEL_6`（PC0）  
- 采样时间：长采样（`ADC_SAMPLETIME_640CYCLES_5`，若目标头文件无该枚举则退到当前可用最大采样时间）  
3. 滤波：
- `N=16` 采样，去掉最大/最小各1个后求平均（trimmed mean）  
4. 电压换算：
- 默认优先 `VREFINT` 计算 `VDDA`  
- 若 `VREFINT` 读取失败，回退 `3300mV`  
5. 电阻公式保持不变：
- `Rx = Rref_eff * Vred / (Vref - Vred)`

## 实施步骤（按顺序）
1. HAL/CMSIS 底座补齐 ADC
- 从本机 `STM32Cube_FW_G4_V1.6.2` 复制：
  - `stm32g4xx_hal_adc.h/.c`
  - `stm32g4xx_hal_adc_ex.h/.c`
  - `stm32g4xx_ll_adc.h`（必要时含 `ll_adc.c`）
- 在 `stm32g4xx_hal_conf.h` 打开 `HAL_ADC_MODULE_ENABLED`
- Clean + Build，确保 ADC HAL 可编译

2. 新增 `drv_adc_internal`
- 在驱动内完成：
  - ADC12 时钟源配置（`SYSCLK`）
  - ADC12/GPIOC 时钟使能
  - PC0 配置为 `Analog, NOPULL`
  - ADC1 Init（12-bit，右对齐，单次）
  - 上电一次校准（`HAL_ADCEx_Calibration_Start`）
- 实现 raw/mV/vdda/filter/status 接口

3. 替换 Measurements 采样链路
- 删除 `#include drv_ads1110.h`
- 删除 `g_ads` 指针和 `ads1110_read_raw` 路径
- 改为 `adc1_read_filtered()` 获取 `Vred`
- `meas_voltage_dc/meas_resistance/meas_diode/meas_resistance_manual` 统一改走内置 ADC
- `measurements_init()` 签名按新接口收敛

4. App 层去 ADS 化
- `App/app.c` 删除：
  - ADS 地址扫描结构与逻辑（`0x48~0x4F`）
  - `ads1110_init/read_raw` 相关调用
- 启动自检改为：
  - `adc1_init()`
  - 读取一次 `raw/mV` 判定 `MOD_ADC1`
- Debug 页：
  - 用 `ADC1` 状态替代原 `I2C3/ADS` 信息
- RES 页面增加三行（按你要求）：
  - `ADC raw: xxxx`
  - `Vred: x.xxx V`
  - `ADC stat: OK/TIMEOUT/OVR`

5. 构建系统与遗留清理
- 取消 `drv_ads1110.*` 的编译参与（Exclude from Build 或从工程源列表移除）
- 保留文件可选（`legacy`），但不得被任何 `.c` 引用
- 当前 `MX_I2C3_Init` 可暂留（不影响功能）；下一里程碑再从 `.ioc` 清理 I2C3

6. 文档更新
- `README.md`：写明“禁止使用 ADS1110，采样改用 ADC1/PC0”
- `debug_ui.md`：状态位/错误码从 ADS 改为 ADC1
- `t1_1_2a_res_manual.md`：采样源改为内置 ADC + 滤波
- `validation_checklist.md`：新增 ADC 原始码与 VREFINT/VDDA 检查项，删除 ADS 地址检查

## 测试用例（必须执行）
1. `T-ADC-BRINGUP-01`
- 条件：RED 节点空载/固定电位  
- 期望：`ADC raw` 有效，`ADC stat=OK`，无超时/OVR

2. `T-ADC-RANGE-02`
- 条件：切换 `2K/20K/200K`  
- 期望：`ADC raw`、`Vred` 有趋势变化

3. `T-RES-TREND-03`
- 条件：接 `10k/100k/1M` 标准电阻  
- 期望：`Rx` 随阻值增大单调增加，趋势正确

4. `T-ERR-ADC-04`
- 条件：模拟 ADC 读失败路径（超时/异常）  
- 期望：页面显示 `ADC stat: TIMEOUT/OVR`，系统不中死

5. `T-NO-ADS-05`
- 条件：完全不接 ADS 模块  
- 期望：系统正常运行，不再出现 ADS 地址扫描相关 UI/日志

## 假设与默认
1. 目标引脚固定为 `PC0 (ADC12_IN6)`。  
2. 暂不重生 `.ioc`，先通过手工驱动完成迁移。  
3. I2C3 初始化暂留但不使用；后续再做 `.ioc` 清理专项。  
4. `VREFINT` 默认启用；失败自动回退到 `3300mV`。  
5. 本里程碑优先“可用与响应稳定”，绝对精度通过后续标定收敛。

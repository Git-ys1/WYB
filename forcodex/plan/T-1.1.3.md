# T-1.1.3 执行计划：按键体验优化 + ADS 接线前健康检查（WYB）

## 摘要
当前代码的电阻算法链路是通顺的（`MUX -> ADS1110 -> Vred -> Rx`），但有两个体验/联调阻塞点：  
1. 按键短按在 `KEY_EVT_UP` 触发，体感迟滞明显。  
2. ADS 地址固定 `0x48` 且读失败统一映射 `ERR_ADC_TIMEOUT`，未接线或地址不符时会误导排障。  

本轮只做 T-1.1.3 相关改造，不改 `.ioc`，目标是“按键跟手 + ADS 接线前可判定代码健康”。

## 设计冻结（决策完备）
1. 按键采样参数：`poll=2ms`、`debounce=10ms`、`long=600ms`。  
2. 菜单动作触发策略：短按动作改为 `KEY_EVT_DOWN` 立即执行。  
3. `OK` 键策略：`短按即时 + 长按回顶`。  
4. ADS 扫描策略：I2C3 扫描 `0x48~0x4F`，按优先级选择首个（`0x48` 优先）。  
5. OLED 调试页必须显示：`ADS FOUND @0x4x` 或 `ADS NOT FOUND`。  

## 实施步骤
1. 按键体验优化（BSP 层）
- 在 `bsp_keys.c` 将消抖常量改为 10ms、长按改为 600ms。  
- 保持事件模型不变（`DOWN/UP/LONG`），不新增复杂 repeat 逻辑。  
- 保证每次稳定按下后 1 个轮询周期内可产出 `KEY_EVT_DOWN`。  

2. 菜单事件切换到 DOWN（App 层）
- 在 `app_poll_button()` 中把原 `KEY_EVT_UP` 的短按导航逻辑迁移到 `KEY_EVT_DOWN`。  
- `KEY_EVT_UP` 仅用于结束态清理，不做菜单动作。  
- `KEY_EVT_LONG + KEY_OK` 在 `MEAS` 分支执行“快速回到一级菜单”。  
- 长按触发后不重复执行额外短按动作（避免一次按压触发两次同类行为）。  

3. ADS 地址扫描与绑定（App 层）
- 新增启动自检函数 `app_ads_scan_bind()`（静态函数即可）：  
  - 循环 `0x48..0x4F` 调 `bsp_i2c_probe(BSP_I2C_BUS_ADS, addr, timeout)`。  
  - 保存命中列表（最多 8 个）并选定工作地址 `ads_addr_active`。  
  - 未命中则标记 `MOD_I2C3/MOD_ADS=FAIL` 并记录日志。  
- `ads1110_init()` 改用 `ads_addr_active`，不再硬编码 `0x48`。  

4. ADS 错误语义修正（Driver 层）
- 在 `drv_ads1110_read_raw()` 中先做一次快速 `probe`：  
  - `probe` 失败返回 `ERR_I2C_NACK`。  
  - `probe` 成功但读失败返回 `ERR_ADC_TIMEOUT`。  
- 保持现有对上层 API 不变，避免牵连测量模块。  

5. OLED 调试可视化增强
- 在 DEBUG 页系统区增加 ADS 行：`ADS: 4A OK` / `ADS: -- FAIL`。  
- 在日志中增加关键事件：`ADS scan`, `ADS bind`, `ADS read err`, `ADS recovered`。  
- 刷新周期保持 200ms，不再引入额外 UI 延时。  

6. 文档同步
- 在 `t1_1_2a_res_manual.md` 更新按键时序与短按定义（改为 DOWN 触发）。  
- 在 `debug_ui.md` 更新 ADS 扫描范围、地址选择优先级、错误码判定建议。  

## 对外接口/类型变更
1. 不新增对外业务 API。  
2. 仅行为变化：  
- 菜单短按触发时机由 `UP` 改为 `DOWN`。  
- ADS 地址来源由固定值改为扫描绑定。  
- ADS 错误码从“全超时”细化为 `NACK/Timeout`。  

## 测试与验收
1. `T-KEY-RESP`：单击任意方向键，OLED 菜单在 200ms 内变化。  
2. `T-KEY-LONG`：`OK` 按住 >600ms，在 MEAS 内回到一级菜单。  
3. `T-ADS-SCAN-NOHW`：ADS 未接时显示 `ADS NOT FOUND`，日志为 `NACK`，系统不死机。  
4. `T-ADS-SCAN-HW`：接入 ADS 后显示 `FOUND @0x4x`，绑定地址稳定。  
5. `T-ADS-RAW-GND-3V3`：`VIN+` 接 GND/3V3 时 raw 与 mV 方向正确。  
6. `T-RES-TREND`：RES 手动 2K/20K/200K 三档趋势正常（绝对误差后续标定再收敛）。

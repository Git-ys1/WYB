# T-1.1.5E-R1 最终执行计划（主分支回稳 + 实验隔离 + 可见 fallback）

## 摘要
本轮只做“回稳 + 防再黑屏”两件事，不推进功能。  
执行顺序固定为：先在 `main` 安全撤销 `c9ca804`，恢复稳定 Smoke 基线；再加实验开关与 presenter 的可见 fallback；最后把菜单重构迁到独立实验分支。

2. `APP_SMOKE_OLED_TEST` 当前为 `0`（默认走菜单壳）。
3. `c9ca804` 改动文件正是 `main.c/app.c/app_ui_presenter.c/.h/README/checklist`，与任务书一致。

## 一、执行范围与冻结

- `Core/Src/main.c`

- 测量算法

## 二、Git 操作步骤（主分支先回稳）
1. 在 `main` 执行安全回退（不改历史）：
- `git checkout main`
- `git pull`
- `git revert --no-edit c9ca804`
- `git push`
2. 回退后立即核查：
- `git log --oneline -n 5` 中出现 revert 提交
- `Core/Src/main.c` 恢复到 Smoke 默认路径（`APP_SMOKE_OLED_TEST=1`）
- `App/app_ui_presenter.c/.h` 被回退删除（这是预期，后续按本计划重新加“防锁死版”）

## 三、主分支默认策略（稳定优先）
在 `Core/Src/main.c` 增加实验总开关，并固定默认关闭：
1. 新增：
- `#define APP_MENU_REINTEGRATION_EXPERIMENT 0`
2. 分流规则改为：
- `APP_MENU_REINTEGRATION_EXPERIMENT=0`：强制走稳定 Smoke 固定页（`OLED TXT OK + RAW/MV/VDDA/STAT`）
- `APP_MENU_REINTEGRATION_EXPERIMENT=1`：才允许走菜单重构路径
3. 保留 LED smoke 分支，不删除任何现有 smoke 代码。

## 四、Presenter 防黑屏（避免“失败后永久无显示”）
在 `App/app_ui_presenter.c`（重新添加）实现“失败不锁死”语义，`App/app.c` 仅做最小接线：
1. API 保持 R2 兼容（不扩业务接口）：
- `app_ui_presenter_init()`
- `app_ui_presenter_ready()`
- `app_ui_presenter_last_err()`
- `app_ui_presenter_flush()`
2. 关键行为改动：
- flush 失败后 **不再** 把 `s_ready` 永久置 `false`
- 维护 `fail_streak`，连续失败时进入 fallback 渲染
- fallback 固定页（ASCII）：
  - `OLED FALLBACK`
  - `ERR: EX3`
  - `USE SMOKE BASE`
  - `CHECK EXP SWITCH`
3. `app.c` 配套规则：
- 若 presenter 返回错误，允许下一周期继续尝试，不进入永久 return 死路径
- 仅在实验路径（开关=1）使用 presenter；主分支默认 smoke 不走 presenter

## 五、菜单重构剥离到实验分支

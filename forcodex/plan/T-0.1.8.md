# STM32G474 万用表 T-0.1.8 决策完备实施计划（面包板首轮验证）

## 1. 计划摘要
目标是在不改硬件拓扑的前提下，完成最小可运行里程碑 4 项并建立可扩展固件骨架：  
1) OLED 点亮并菜单切换；2) ADS1110 原始码/mV 显示；3) PA0 输入捕获频率/占空比显示；4) 切换 CD4051 通道时 ADS 读数可见变化。  
固件架构固定为 `HAL + Superloop`，`KEY=PC13`，`BEEP=PB8`，标定参数采用“编译期常量 + 预留 Flash 接口”。

## 2. 冻结的硬件与外设映射
| 模块 | 引脚/外设 | 决策 |
|---|---|---|
| ADS1110 | I2C3: PC8/PC9 | 固定硬件 I2C3 |
| OLED | I2C2: PC4/PA8 | 优先硬件 I2C2，若 AF 不可用则软件 I2C 保持接线不变 |
| 电阻档 CD4051(U4) | PD5/PD6/PD7 | A/B/C 地址线 |
| 模式 CD4051(U9) | PB4/PB5/PB6 | A/B/C 地址线 |
| 电压档 CD4051(U11) | PB13/PB14 | A/B 地址线 |
| 频率输入 | PA0 | 输入捕获通道固定在 PA0 对应定时器通道 |
| 按键 | PC13 | EXTI + 软件去抖 |
| 蜂鸣器 | PB8 | TIM16_CH1 PWM（不通则先 GPIO 方波） |

## 3. 工程结构与代码分层
工程目录固定为 `./fw_t018_g474/`（新建 CubeMX/CubeIDE 工程）。模块分层如下：  
- `App/`：状态机、调度、UI 页面、错误处理。  
- `Drivers/`：OLED、ADS1110、4051、按键、蜂鸣器、频率捕获。  
- `Measurements/`：VDC/RES/CONT/DIODE/FREQ 算法。  
- `Calib/`：标定参数、参数装载接口。  
- `BSP/`：板级 pin 宏、外设句柄绑定。

主循环固定：
```c
while (1) {
    app_poll_button();
    app_measure_tick();
    app_ui_tick();
    app_beep_tick();
}
```

## 5. 公共接口与类型（冻结）
### 5.1 驱动接口
- `oled_init/oled_clear/oled_draw_text/oled_draw_big_num/oled_flush`
- `ads1110_init/ads1110_set_cfg/ads1110_read_raw/ads1110_read_mv`
- `mux_set_res_range/mux_set_mode/mux_set_volt_range`
- `freq_start/freq_get_hz/freq_get_duty`
- `button_poll/button_get_event`（`BTN_SHORT/BTN_LONG`）
- `beep_once/beep_continuous/beep_pattern/beep_tick`

### 5.2 业务类型
- `app_mode_t`: `MODE_VDC, MODE_RES, MODE_FREQ, MODE_CONT, MODE_DIODE`
- `app_range_t`: 按模式分别定义离散档位枚举
- `meas_result_t`: `value, unit, flags, err`
- `app_err_t`: `ERR_OK, ERR_I2C_NACK, ERR_ADC_TIMEOUT, ERR_OVERRANGE, ERR_NO_SIGNAL`

### 5.3 标定接口
- `calib_load(calib_profile_t *out)`：0.1.8 从编译期默认参数装载
- `calib_save(const calib_profile_t *in)`：0.1.8 返回未实现错误码，接口保留
- `calib_profile_t` 固定包含：每档 `k,b`、电压分压比、每档 `Rref`

## 6. 算法与参数默认值（冻结）
- ADS1110：连续转换，统一超时机制，读数做 `median(5)` 去毛刺。  
- VDC：先选 U11 再选 U9，再读 ADC 并套 `V = k*adc + b`。  
- RES：`Rx = Rref * Vred / (Vexc - Vred)`；当 `Vexc - Vred < epsilon` 判开路。  
- CONT：`Rx < 10Ω` 持续 120ms 触发蜂鸣；`Rx > 15Ω` 持续 120ms 解除。  
- DIODE：显示 `Vf` 与极性/不导通提示（按当前硬件方向能力）。  
- FREQ/DUTY：输入捕获双沿测量，20Hz~200kHz 通过动态平均窗口稳定显示。  
- 按键判定：短按 `<300ms`，长按 `>800ms`，中间区间忽略。  
- 蜂鸣器：默认 PWM 2.7kHz，支持单次/持续/告警三模式。

## 8. 风险与兜底策略（已定）
- 若 `PC4/PA8` 无法启用硬件 I2C2：OLED 切软件 I2C，其他模块不改。  
- 若 PB8 PWM映射受限：先 GPIO 方波蜂鸣，接口保持不变。  
- 若输入捕获噪声大：提高比较器迟滞并在固件端增大中位数窗口。  
- 全部 I2C 线必须上拉 3.3V，禁止 5V 上拉。

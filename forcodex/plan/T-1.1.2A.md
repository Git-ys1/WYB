# T-1.1.2A 执行计划：6键输入 + 菜单导航 + 电阻手动档（基于 `WYB`）

## 摘要
在不改 `.ioc` 的前提下，新增 6 键轮询输入模块，替换当前单键交互为“层级菜单 + RES 手动档”流程，先打通 `2K/20K/200K` 三档电阻测量，`AUTO/200Ω` 先显示占位。  
现有 `T-0.1.12` 的 OLED 调试页、日志系统、模块状态位继续保留并复用。

## 目标完成定义（DoD）
1. 6 键可用：`UP/DOWN/LEFT/RIGHT/OK/BACK`，20ms 消抖，短按和长按（>800ms）可区分。  
2. 菜单可导航：`L1 模块 -> L2/L3/L4`，可进入 `RES MANUAL` 页面。  
3. RES 手动档可切 `2K/20K/200K`，切档后 CD4051 通道联动，`Rx` 随被测电阻变化。  
4. 错误进入日志和状态位：I2C/ADS 失败在 DEBUG 页可见。  
5. 工程可编译（CubeIDE Debug 配置通过）。

## 3. 6键输入实现方案（bsp_keys）
1. 引脚冻结：
- OK=`PC13`
- UP=`PB0`
- DOWN=`PB1`
- LEFT=`PB2`
- RIGHT=`PB10`
- BACK=`PB11`

2. `bsp_keys_init()` 行为：
- 使能 `GPIOB/GPIOC` 时钟。
- 将上述 6 引脚统一配置为 `GPIO_MODE_INPUT + GPIO_PULLUP`。
- 说明：PC13 即使 CubeMX 当前是 EXTI，也在运行时改为输入上拉，采用纯轮询方案。

3. 轮询与消抖：
- `keys_poll()` 内部节拍固定 `2ms`（满足 1~5ms）。
- 每键独立状态机：原始电平、稳定电平、最后变化时间、按下起始时间、long 是否已触发。
- 消抖阈值：`20ms`。
- 事件策略：
- 稳定按下触发 `KEY_EVT_DOWN`。
- 稳定释放触发 `KEY_EVT_UP`。
- 按住超过 `800ms` 触发一次 `KEY_EVT_LONG`。
- `KEY_EVT_REPEAT` 先保留枚举，默认关闭（不产生事件）。

4. 短按定义：
- 短按由应用层判定为“收到 `KEY_EVT_UP` 且该次未触发 LONG”。

## 4. 菜单状态机（替换当前单键逻辑）
1. 菜单层级定义：
- `L1_MODULE`：模块选择（DEBUG / MEAS）。
- `L2_DEBUG_PAGE`：调试页（沿用当前 T-0.1.12 DEBUG UI）。
- `L2_MEAS_FUNC`：测量功能选择（本轮仅 RES）。
- `L3_RES_RANGE`：`AUTO / 200 / 2K / 20K / 200K`。
- `L4_RES_RUN`：RES 手动测量运行页。

2. 按键规则（短按）：
- `UP/DOWN`：当前层光标上下移动（循环）。
- `LEFT/RIGHT`：
- 在 `L1_MODULE`：左=DEBUG，右=MEAS（硬切换）。
- 在 `L3_RES_RANGE` 和 `L4_RES_RUN`：作为范围切换快捷键（与 UP/DOWN 同效）。
- `OK`：进入下一级或确认当前项。
- `BACK`：返回上一级。

3. 按键规则（长按）：
- 在任意 MEAS 层（`L2_MEAS_FUNC/L3_RES_RANGE/L4_RES_RUN`），`OK` 长按快速回 `L1_MODULE`。
- 其他长按默认忽略（仅日志记录）。

4. 兼容策略：
- `drv_button.*` 暂不删除，但 `app.c` 不再调用 `button_poll/button_get_event`。

## 5. RES 手动档实现（本轮核心）
1. 档位与通道映射（冻结）：
- `RES_RANGE_2K` -> `CH1` -> `mux_set_res_range(RES_RANGE_2K)` -> `Rref_eff=10k`
- `RES_RANGE_20K` -> `CH2` -> `mux_set_res_range(RES_RANGE_20K)` -> `Rref_eff=100k`
- `RES_RANGE_200K` -> `CH3` -> `mux_set_res_range(RES_RANGE_200K)` -> `Rref_eff=1M`
- `RES_RANGE_200` -> `CH0` 先不测量，页面显示 `NOT READY`
- `AUTO` 先占位，页面显示 `NOT READY`

2. 测量流程（手动档）：
- 先 `mux_set_mode(MUX_MODE_RES)`。
- 再按档位设置 `mux_set_res_range(...)`。
- 读取 `Vred`（优先 `median(5)` 的 mV；并记录一次 raw 供显示）。
- 计算：
`Rx = Rref_eff * Vred / (Vref - Vred)`，`Vref=3.300V`。
- 当 `Vref - Vred <= 0.02V` 判开路/超量程，置 `ERR_OVERRANGE`。

3. OLED 运行页（L4）固定 5 行：
- `L1: RES MANUAL`
- `L2: RANGE: 2K/20K/200K`
- `L3: Vred: x.xxx V`
- `L4: Rx: xxxx Ohm`（必要时自动切 `kOhm`）
- `L5: raw:xxxxx err:x`

4. 200Ω与AUTO占位行为：
- 不进入计算，直接显示 `NOT READY`。
- 保留日志提示一次：`LOGW("RES 200 not ready")` 或 `LOGW("RES AUTO not ready")`。

## 6. 日志与状态位联动
1. ADS/I2C 错误：
- 记录 `LOGE("RES ADC E%d", err)`。
- `MOD_ADS` 置 FAIL（沿用 `module_set` 去重）。
2. 恢复：
- 下次成功后 `MOD_ADS` 回 OK，并 `LOGI("RES ADC RECOVER")`。
3. MUX 切档动作：
- 每次切档记录 `LOGI("RES RNG %s", ...)`，便于定位通道错误。

## 8. 验收测试（必须逐项）
1. `T-KEY-01`：六键单击，均有 `DOWN/UP` 事件，误触发率低。  
2. `T-KEY-02`：六键长按>800ms，均可触发 `LONG`，且短按动作不重复触发。  
3. `T-MENU-01`：`L1(DEBUG/MEAS)` 左右切换正确。  
4. `T-MENU-02`：`MEAS -> RES -> RANGE -> RUN` 路径可达，`BACK` 可逐级返回。  
5. `T-RES-01`：`2K/20K/200K` 切档时，日志显示档位切换，读数发生可见变化。  
6. `T-RES-02`：已知电阻点测量方向正确（阻值增大，计算值同步增大）。  
7. `T-RES-03`：开路时显示 `OVERRANGE/OPEN`。  
8. `T-RES-04`：`200/AUTO` 显示 `NOT READY`，系统不中断。  
9. `T-ERR-01`：断开 ADS/I2C 后，DEBUG 状态位 FAIL + 日志报错；恢复后可回 OK。  
10. `T-BUILD-01`：CubeIDE Debug 构建通过（0 error）。

## 9. 风险与缓解
1. 风险：PC13 从 EXTI 改成输入轮询后，旧 EXTI 路径失效。  
缓解：本轮统一采用轮询，不依赖 EXTI；保留 EXTI NVIC 不影响功能。  

2. 风险：Rref_eff 与真实硬件不一致导致绝对误差大。  
缓解：本轮先保证“切档联动与趋势正确”，后续在 `calib` 加标定补偿。  

3. 风险：菜单改造影响现有旧测量模式逻辑。  
缓解：保留旧测量函数，不删；仅改 `app` 入口状态机，不动底层驱动接口。

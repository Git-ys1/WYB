## T-1.1.4K 最小 OLED-only 烟雾测试最终计划（仅改 [main.c](/F:/CodeForge/STM32CubeIDE_2.1.0/WorkSpace3/WYB/Core/Src/main.c)）

### 摘要
本轮只做 OLED 底层链路判定，不修现有架构。  
通过 `main.c` 编译开关新增 OLED-only 路径，并与现有 LED smoke、业务路径三选一互斥运行：

1. `APP_SMOKE_OLED_TEST=1`：只跑 OLED-only 烟雾测试。  
2. `APP_SMOKE_OLED_TEST=0 && APP_SMOKE_LED_TEST=1`：跑 PB12 LED smoke。  
3. 全部为 `0`：回原业务入口（`bsp_init/app_init/superloop`）。

---

### 公开接口/类型变化
无对外 API 变化。仅新增 `main.c` 内部宏和静态函数：
- `APP_SMOKE_OLED_TEST`
- `SmokeOled_InitI2C2()`
- `SmokeOled_ProbeAddr()`
- `SmokeOled_SendCmd()`
- `SmokeOled_FlushBuffer()`
- `SmokeOled_TestPattern()`
- `SmokeOled_Run()`
- `SmokeLed_BlinkError(code)`（复用 PB12 故障码）

---

### 设计冻结（实现决策）
1. 仅改 [main.c](/F:/CodeForge/STM32CubeIDE_2.1.0/WorkSpace3/WYB/Core/Src/main.c)，不改 `.ioc`、不改 `App/BSP/Drivers/Measurements`。  
2. OLED-only 路径不调用 `bsp_init()`、`app_init()`，不进入现有 `app_*_tick`。  
3. OLED-only 路径固定硬件 I2C2（100k），只探测 `0x3C/0x3D`。  
4. 不使用 Soft-I2C、不使用 recovery 状态机、不使用 dirty flush。  
5. SSD1306 命令/数据全部在 `main.c` 里直接通过 `HAL_I2C_*` 发送，彻底隔离现有架构污染。  
6. PB12 始终保留故障编码灯：
- `1` 次短闪循环：Probe 失败
- `2` 次短闪循环：Init 失败
- `3` 次短闪循环：Flush 失败
- 正常运行：PB12 常灭

### 详细实施步骤

#### Step 1：新增编译开关与函数声明（`USER CODE` 区）
在 `/* USER CODE BEGIN PD */` 增加：
- `#define APP_SMOKE_OLED_TEST 1`
- 保留现有 `#define APP_SMOKE_LED_TEST ...`

在 `/* USER CODE BEGIN PFP */` 增加 OLED-only 静态函数声明。

#### Step 2：实现 OLED-only 本地最小驱动（`USER CODE BEGIN 0`）
新增常量：
- `OLED_W=128`, `OLED_H=64`, `OLED_PAGES=8`
- `OLED_ADDR_3C=0x3C`, `OLED_ADDR_3D=0x3D`
- `OLED_TRIALS=5`, `OLED_TIMEOUT_MS=20`

新增静态数据：
- `static uint8_t s_oled_addr;`
- `static uint8_t s_fb[1024];`

新增函数：
1. `SmokeLed_BlinkError(uint8_t code)`
- 无限循环，按 `code` 次短闪（例如亮100ms灭100ms，组间隔600ms）。

2. `SmokeOled_ProbeAddr(void)`
- `HAL_I2C_IsDeviceReady(&hi2c2, addr<<1, 5, 20)` 依次探测 `0x3C`、`0x3D`。
- 成功保存 `s_oled_addr` 并返回 `true`，失败返回 `false`。

3. `SmokeOled_SendCmd(uint8_t cmd)`
- 发送 `{0x00, cmd}` 到 `s_oled_addr`。

4. `SmokeOled_SendDataPage(uint8_t page, const uint8_t *data128)`
- 先发页定位命令：`0xB0+page, 0x00, 0x10`。
- 再发 `0x40 + 128字节数据`（129 字节包）。

5. `SmokeOled_FlushBuffer(const uint8_t *fb1024)`
- 循环 8 页调用 `SmokeOled_SendDataPage`，任何失败返回 `false`。

6. `SmokeOled_InitPanel(void)`（最小初始化序列）
- 建议固定序列：
`AE D5 80 A8 3F D3 00 40 A1 C8 DA 12 81 7F A4 A6 8D 14 AF`
- 任一步失败返回 `false`。

7. `SmokeOled_TestPattern(void)`
- 阶段A（命令路径）：
  - `A5`，`HAL_Delay(500)`
  - `A4`，`HAL_Delay(200)`
- 阶段B（数据路径）：
  - 全黑 `0x00` flush，`HAL_Delay(500)`
  - 全白 `0xFF` flush，`HAL_Delay(500)`
  - 棋盘格：偶数页 `0xAA`，奇数页 `0x55`，flush，`HAL_Delay(1000)`
- 阶段C（文本路径）：
  - clear + flush
  - 简单 5x7 位图字符（仅实现 `OLED OK`, `ADDR:xx`, `CNT:xxxx` 需要字符集）
  - 每 500ms 递增计数并整屏 flush 一次

8. `SmokeOled_Run(void)`
- `PB12` 默认拉低（正常时熄灭）
- `if !Probe -> BlinkError(1)`
- `if !Init -> BlinkError(2)`
- `if !任何 flush 失败 -> BlinkError(3)`
- 正常则循环计数显示（500ms 刷新）

#### Step 3：`main()` 三路互斥分流
保留 `HAL_Init()`、`SystemClock_Config()`、`MX_GPIO_Init()`。  
初始化阶段分流：

1. `#if APP_SMOKE_OLED_TEST`
- 调 `MX_I2C2_Init()`
- 调 `SmokeLed_Init()`
- 调 `SmokeOled_Run()`（不返回）
- 不调用 `MX_I2C3_Init/MX_TIM2_Init/MX_TIM16_Init`
- 不调用 `bsp_init()/app_init()`
- 不进入业务 while 逻辑

2. `#elif APP_SMOKE_LED_TEST`
- 保持你当前 LED smoke 路径（PB12 1秒常亮+100ms翻转）

3. `#else`
- 完整保留原业务初始化和 `app_poll_button/app_measure_tick/app_ui_tick/app_beep_tick`

#### Step 4：回切规则（写到注释）
在 `main.c` 顶部宏处注明：
- OLED-only：`APP_SMOKE_OLED_TEST 1`
- LED-only：`APP_SMOKE_OLED_TEST 0` 且 `APP_SMOKE_LED_TEST 1`
- 原业务：两个宏都 `0`

### 测试用例与验收场景

1. `T114K-OLED-01 命令路径`
- 期望：上电后先出现 `A5` 全亮 500ms，再回 `A4`。

2. `T114K-OLED-02 数据路径`
- 期望：依次看到 全黑 -> 全白 -> 棋盘格。

3. `T114K-OLED-03 文本路径`
- 期望：显示 `OLED OK`、`ADDR:3C/3D`，计数 `CNT:0001...` 每 500ms 更新。

4. `T114K-ERR-01 故障码灯`
- Probe失败：PB12 1闪循环。
- Init失败：PB12 2闪循环。
- Flush失败：PB12 3闪循环。

5. `T114K-DIAG-01 结论判定`
- 若 A5/A4 正常但棋盘格/文本异常：判定 GDDRAM/数据控制路径问题。
- 若 A5 都无效：判定 I2C2 地址/初始化基础链路不通。
- 若 OLED-only 完全正常：判定当前主工程是架构污染问题。

---

### 显式假设与默认
1. OLED 为 SSD1306 兼容，地址仅 `0x3C/0x3D`。  
2. I2C2 保持 `MX_I2C2_Init()` 现有 100k timing。  
3. `PB12` 外接 LED 接法沿用上一轮验证（Active-High）。  
4. 本轮允许在 smoke 模式中使用 `HAL_Delay`（仅为链路烟雾测试）。  
5. 本轮不推进 T-1.1.5，不改任何业务测量逻辑。
